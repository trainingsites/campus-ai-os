# Setup Progress

Your campus works right now with everything below at defaults. Each file you
fill in makes the work more *yours*. Dean will ask about these one at a time,
at natural moments  -  or run **`/full-onboarding`** to do them all in one
sitting (it picks up wherever you left off and never re-asks what's done).

| File | What it does | Status |
|---|---|---|
| `shared/voice.md` | How you sound  -  so drafts read like you wrote them | DEFAULT |
| `shared/goals.md` | The one number, the horizon, this week's focus | DEFAULT |
| `shared/audience.md` | Who you serve (seeded from setup) | SEEDED |
| `shared/offers.md` | What you sell and for how much | DEFAULT |
| `shared/tools.md` | What's connected (email, community, calendar) | DEFAULT |

Priority order: voice -> goals -> audience -> offers -> tools.

Status meaning: **DEFAULT** = generic placeholder, Dean guesses until you fill
it. **SEEDED** = your raw setup answer is in, not yet expanded. **DRAFTED** =
Dean expanded it into a real draft that needs your corrections ("fix my
{audience} file"). **COMPLETE** = you confirmed it.
